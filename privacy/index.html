HealthOS · Política de privacidad — entorno de STAGING

Versión 1.0 · 2026-09-06 · Aplica ÚNICAMENTE al entorno de pruebas

t; Este documento describe un sistema en pruebas que trata **exclusivamente datos
t; sintéticos**. No hay pacientes reales, no hay historia clínica de ninguna persona y no se
t; presta ningún servicio sanitario. Si has llegado aquí buscando la política de un producto
t; en funcionamiento, ese producto todavía no existe.

Quién trata los datos

HealthOS, sistema de acompañamiento en desarrollo. Responsable: el titular del despliegue de

staging. Contacto: el que figura en la configuración de la aplicación de Meta asociada.

Qué datos se tratan en staging

DatoOrigenCómo se guarda
Número de teléfono del destinatario de pruebaWhatsApp Cloud APIHMAC-SHA256, nunca en claro
Texto de los mensajes de pruebaWhatsApp Cloud APIContenido sintético, en base de datos de staging
Identificadores técnicos de MetaWhatsApp Cloud APIprovider_message_id, phone_number_id
Marcas de tiempo y estados de entregaWhatsApp Cloud APIFechas y estados

El número de teléfono no se almacena en claro en ningún momento. Se guarda un HMAC con

una clave del sistema, de modo que la base de datos no contiene una lista de teléfonos.

Qué NO se hace

  • No se trata información de salud de ninguna persona real.
  • No se emiten diagnósticos, recetas ni cambios de tratamiento.
  • No se comparten datos con terceros distintos de Meta, que es el transportista del canal.
  • No se usan los datos para publicidad, perfilado ni entrenamiento de modelos.
  • No se transfieren datos fuera del entorno de staging.

    • Base legal

    Consentimiento explícito de la única persona autorizada como destinatario de prueba, que es

    además quien opera el despliegue. No hay terceros implicados.

    Conservación

    Los datos de staging se conservan mientras dura la certificación y se eliminan al retirar el

    entorno. No hay copia de seguridad destinada a conservarlos a largo plazo.

    Derechos

    Al tratarse de una única persona que es a la vez titular y operadora del sistema, el ejercicio

    de los derechos de acceso, rectificación, supresión, limitación, portabilidad y oposición se

    realiza directamente sobre el entorno. La supresión completa se consigue retirando el

    despliegue, lo que borra la base de datos y el almacén de objetos.

    Eliminación de datos

    Ver docs/legal/ELIMINACION_DATOS_STAGING.md.

    Cambios

    Cualquier cambio en el alcance —en particular, admitir datos de personas reales— exige

    sustituir este documento por una política de producto real, con responsable identificado,

    base legal documentada y evaluación de impacto. Hasta entonces, este texto describe lo que

    hay: un laboratorio.
